# Карта Аркс-Феррума

Отдельная страница сайта. Quartz копирует папку `quartz/static/arx` как есть,
поэтому после `npx quartz sync` карта открывается по адресу:

- на сайте: https://toster69.github.io/avolar/static/arx/
- локально: http://localhost:8080/static/arx/

Ссылка сразу на место: `…/static/arx/#13` (по номеру), `…/static/arx/#Ступени`, `…/static/arx/#Инга`.

## Файлы

| Файл | Что внутри |
|---|---|
| `data.js` | места, районы, персонажи, слои — **правьте здесь** |
| `map.webp` | карта 3600 × 5400 (загружается при приближении) |
| `map_lo.webp` | облегчённая карта для быстрого открытия |
| `roads.png` | сетка улиц для маршрутов (по ней ищется путь) |
| `index.html`, `arx.css`, `arx.js` | страница, оформление, интерактив |

## Как править `data.js`

- **Место без статьи** показывает только название. Когда статья появится, впишите `page: "Название статьи"` —
  ссылка «Читать в базе» появится сама. Описание `text` показывается только у мест со статьёй.
- **Координаты** `x`, `y` — проценты от карты. Кнопка с прицелом на карте копирует координаты клика.
- **Персонажи** — список `people`. `at` — где он: `{ place: 13 }` (номер места) или `{ district: "Ступени" }`.
  Первая точка — где стоит значок. Портрет и описание берутся из статьи персонажа.
- **Слои** — список `layers`: название и цвет рамки значков.

## Маршруты

Путь ищется по сетке `roads.png`, снятой с карты: главные дороги и мосты — самые «дешёвые»,
река, ущелья и горы — непроходимы. Если поменяете карту, сетку нужно пересобрать заново.
