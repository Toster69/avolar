# Новая главная Аволара

Плагин для Quartz. Он рисует интерактивную главную страницу поверх `content/index.md` и сам файл не трогает.

## Включить и выключить

В `quartz.config.yaml` найдите блок:

```yaml
  - source: ./plugins/avolar-home
    enabled: true
```

- `true` — новая главная.
- `false` — классическая главная из `content/index.md`, как было раньше. После сборки сайт полностью совпадает со старым.

## Что редактировать

Весь текст новой главной хранится в `home.yaml`:

- карточки «Выберите путь»;
- события «Шкалы Тьмы»;
- плитки «Мир в пяти ссылках»;
- дата следующей игры для таймера (`nextSession`);
- курсор и звук (`atmosphere`).

Страницы указывайте по названию, как в Obsidian («Живой Металл»), а картинки — по имени файла («red_line.webp»). Если что-то не найдётся, при сборке появится предупреждение `[avolar-home]`.

Блок «Последнее обновление» сам берёт верхний раздел `## Обновление …` из «Анонсов и Новостей». «Недавно дополнены» строится по датам изменения статей, а видео — последнее загруженное на канал.

## Файлы

| Файл | Что внутри |
|---|---|
| `home.yaml` | тексты и настройки |
| `home.css` | оформление (цвета берутся из темы сайта) |
| `home.client.js` | интерактив: карточки, шкала, граф, звук, таймер |
| `dist/components/index.js` | сборка HTML главной из `home.yaml` |
