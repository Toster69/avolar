# Карта Аволара — интерактивная страница «Карта»

Плагин для Quartz. Заменяет страницу «Карта» по тому же адресу, сам `content/Карта.md` не трогает.

## Включить и выключить

`quartz.config.yaml`, блок `./plugins/avolar-atlas`:
- `enabled: true` — новая карта;
- `enabled: false` — старая страница, полностью как раньше.

## Что на странице

- Карта на всю ширину и почти на всю высоту окна: зум колесом, кнопками и жестами,
  перетаскивание, полноэкранный режим, легенда, обзорная мини-карта при приближении.
- Метки — те же ромбы, что на мини-карте главной. Наведение — краткое превью,
  клик — карточка места с артом, описанием и кнопкой «Читать статью».
- Под картой — строка «Показывать»: города, крепости, знаковые места
  и Красная Полоса. Выбор запоминается в браузере. «Скрыть все значки» — одной кнопкой.
- Ниже — блок «Границы».
- Кнопка «Координаты» на карте копирует `x` и `y` для `atlas.yaml`.
- Ссылка вида `…/карта#Зирк` сразу открывает карточку Зирка.

## Что где править — `atlas.yaml`

| Что | Где |
|---|---|
| Города и крепости (координаты, тип, подпись) | `places` |
| Знаковые места (Кладбище Идей, 17-е орудие…) | `sites` |
| Тексты «Границы» | `sides` |
| Масштаб для линейки | `kmPerMapWidth`, `kmPerDay` |
